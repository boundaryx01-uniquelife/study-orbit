# STUDY ORBIT

> Record less. Learn more.  
> 기록은 짧게, 학습은 깊게.

STUDY ORBIT는 특목고·과학고·영재학교 등을 준비하는 학생을 위한 학습 기록 PWA입니다.

핵심 목표는 학생이 앱에 오래 머무는 것이 아니라, **공부의 시작과 끝을 짧게 정돈하고 학습의 흔적을 자연스럽게 축적하는 것**입니다.

## Product Direction

- 공부 시작 전: 오늘 할 학습을 짧게 확인
- 공부 중: 앱 개입 최소화
- 공부 종료 후: 20초 이내에 결과 기록
- 문제집별 진도·정답률·오답률 누적
- 기억할 가치가 있는 오답만 선택 기록
- 완료한 문제집은 Archive에 보존
- 주간·월간 리포트는 필요할 때만 확인
