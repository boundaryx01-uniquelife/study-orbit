# STUDY ORBIT MVP v0.1

## Goal
학생이 하루 학습을 방해받지 않고 다음 흐름을 자연스럽게 완료할 수 있는지 검증한다.

`Today → Start → Study → Finish → Record`

## Screens

### 1. Today
- 오늘의 학습 목표 확인
- 목표 설정은 선택
- 바로 공부 시작 가능
- 오늘 개인공부 시간 요약

### 2. Study
#### 개인공부
- 과목 선택
- 문제집 선택
- 타이머 시작
- 학습 종료

#### 학원 숙제
- 타이머 없이 사후 기록 가능
- 과목
- 문제집
- 소요 시간
- 풀이 문제 수
- 오답 수

### 3. Books
문제집별 핵심 데이터:
- 제목
- 과목
- 전체 문제 수
- 누적 풀이 문제 수
- 누적 정답/오답
- 누적 정답률 또는 오답률
- 진행률
- 총 학습시간
- 기억할 문제 수

### 4. Remembered Problems
수학 문제집 중심의 선택 기록:
- 문제 번호
- 오답 원인
- 한 줄 메모
- 사진은 후속 구현 가능

오답 원인 기본값:
- 개념 부족
- 계산 실수
- 조건 누락
- 문제 이해
- 풀이 전략
- 기타

모든 오답을 기록하도록 강제하지 않는다.

### 5. Report
MVP 최소 지표:
- 총 학습시간
- 개인공부 시간
- 학원 숙제 시간
- 자기주도 학습 비율
- 과목별 학습시간
- 총 풀이 문제 수
- 정답률

### 6. Archive
문제집 완료 시 보관:
- 전체 문제 수
- 최종 정답률
- 총 학습시간
- 기억할 문제 수
- 학습 이력

## MVP Acceptance Questions
1. 공부 시작까지 5초 안에 가능한가?
2. 학습 중 앱을 다시 볼 필요가 없는가?
3. 종료 기록이 20초 안에 가능한가?
4. 문제집 진도와 정답률이 자동 누적되는가?
5. 학원 숙제 기록 방식이 충분히 간단한가?
6. 리포트가 과도한 앱 확인을 유도하지 않는가?
7. Archive가 완주 기록으로 의미가 있는가?

## Explicitly Out of Scope for v0.1
- 로그인
- 서버/DB
- 클라우드 동기화
- 친구/랭킹/SNS
- 과도한 배지/스트릭
- AI 코치
- 복잡한 오답노트
- 문제집 자동 검색 API
- 실제 표지 자동 수집
- 탐구일지

문제집 검색과 표지 등록은 MVP 사용성 검증 후 우선순위를 재평가한다.
