# STUDY ORBIT MVP v0.2

## 핵심 방향

v0.2는 v0.1의 기능 골격을 유지하되, 학생이 흥미를 느낄 수 있는 ORBIT 테마 UI와 문제집 검색 등록 경험을 추가한다.

## 유지 원칙

- 공부 전 입력은 5초 안에 끝난다.
- 공부 후 기록은 20초 안에 끝난다.
- 학습 중 앱 화면 확인을 요구하지 않는다.
- 통계는 자주 보게 만들지 않고 주간 점검 중심으로 둔다.
- 오답 기록은 모든 오답이 아니라 기억할 문제만 선택적으로 남긴다.

## v0.2 포함

- 딥 네이비 우주 배경
- 오늘의 궤도 UI
- 문제집 행성/표지 카드
- 문제집 검색 추가 mock
- 문제집별 진행률, 풀이 수, 오답 수, 정답률
- 개인공부 타이머
- 학원 숙제 수동 기록
- 기록관

## v0.2 제외

- 실제 API 키 연결
- 서버 DB
- 로그인
-클라우드 동기화
- AI 코치
- OCR 문제 수 자동 계산
- 학생 간 랭킹
